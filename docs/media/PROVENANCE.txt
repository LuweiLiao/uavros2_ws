UAVROS 2 documentation media / 文档演示媒体
========================================

Scope: tsduav_quad, tilt_quadcopter, Scorpio; ROS 2 Jazzy + Gazebo Harmonic GUI + ArduPilot SITL.
All source MP4 files are produced by Gazebo GUI's built-in VideoRecorder.
No desktop/window capture, external screen recorder, generated animation or camera-stream encoder is used.
The temporary Qt controller only loads the official plugin and invokes its native OnStart / OnStop / OnSave slots.
GUI capture records the Gazebo scene camera, not the surrounding desktop or application chrome.
Official source: https://github.com/gazebosim/gz-sim/tree/gz-sim8/src/gui/plugins/video_recorder
VideoRecorder.qml defaults its save dialog to shortcuts.home; original recordings are saved there.
MP4 publication copies are byte-identical to their native originals.
GIF files are offline OpenCV decode + Pillow format conversions, explicitly approved by the user on 2026-09-07.
Only time selection, frame sampling, resizing, documented spatial cropping and palette conversion are performed; no flight motion is fabricated.
GIF time selections and playback multipliers refer to native video presentation time, recorded using simulation time.
VideoRecorder lockstep=false: rendered frames may be sampled/dropped under load; videos are demonstrations, not timing measurements.
Flight telemetry remains the source for quantitative flight acceptance.
Diagnostics and temporary capture/conversion programs are not delivered under src/ or docs/.

Baseline source revision for these recordings: 25a6678b8a02e0e5068b5845ad2b210421914776.
Runtime uses native default GZ_PARTITION (unset), host llw-Mech, user llw.
Per-file original locations, worlds, firmware, report IDs, conversion settings and SHA-256 values follow.
Local paths describe reproducibility/provenance on the test host; they are not prerequisites for viewing the repository media.
